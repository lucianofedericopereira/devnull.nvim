Read-only client for the public dev-null.sh API. Requires Neovim 0.10+ and
curl.

==============================================================================
1. COMMANDS                                          *devnull-commands*

                                                              *:DevNull*
:DevNull                    Open the profile of the configured `username`.
:DevNull {username}         Open {username}'s profile and commits.
:DevNull user {username}    Same as above.
:DevNull commit {id}        Open a commit. {id} may also be a dev-null.sh
                            commit URL.

==============================================================================
2. KEYMAPS                                            *devnull-keymaps*

  <CR>   Open the commit under the cursor
  gx     Open the commit (or profile) in the browser
  a      Open the author's profile
  p      Open the parent commit of a reply
  yu     Yank the URL to the + and " registers
  ]]     Load the next page
  t      Toggle replies in the timeline
  R      Refresh
  q      Close the buffer
  g?     Show keymaps

==============================================================================
3. CONFIGURATION                                       *devnull-config*

>lua
  require("devnull").setup({
    base_url = "https://dev-null.sh",
    username = nil,
    open = "tab",        -- "tab" | "split" | "vsplit" | "current"
    timeout = 10000,
    keymaps = {
      open = "<CR>", browser = "gx", more = "]]", refresh = "R",
      replies = "t", parent = "p", author = "a", yank = "yu",
      close = "q", help = "g?",
    },
  })
<
Set any keymap to `false` to disable it.
